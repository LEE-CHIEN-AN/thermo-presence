# YOLO 訓練結果解讀指南

本指南幫助你理解 YOLO 訓練和驗證產生的各種結果文件。

## 📊 結果文件位置

### 1. 訓練過程記錄
- **`yolo_training/runs/train/results.csv`** - 每個 epoch 的詳細指標
- **`yolo_training/runs/train/`** - 訓練過程中的圖表和批次影像

### 2. 驗證結果
- **`runs/detect/val/`** 或 **`runs/detect/val2/`** - 驗證集的詳細結果
- 包含圖表、混淆矩陣、預測影像等

## 📈 1. results.csv 解讀

### CSV 欄位說明

| 欄位 | 說明 | 理想值 |
|------|------|--------|
| **epoch** | 訓練輪數 | 1-200 |
| **time** | 累積訓練時間（秒） | - |
| **train/box_loss** | 訓練集 bounding box 損失 | 越小越好（< 1.0） |
| **train/cls_loss** | 訓練集分類損失 | 越小越好（< 0.5） |
| **train/dfl_loss** | 訓練集分布損失 | 越小越好（< 1.2） |
| **metrics/precision(B)** | 精確度（Precision） | 越高越好（> 0.95） |
| **metrics/recall(B)** | 召回率（Recall） | 越高越好（> 0.90） |
| **metrics/mAP50(B)** | mAP@0.5 IoU | 越高越好（> 0.95） |
| **metrics/mAP50-95(B)** | mAP@0.5:0.95 IoU | 越高越好（> 0.70） |
| **val/box_loss** | 驗證集 bounding box 損失 | 越小越好 |
| **val/cls_loss** | 驗證集分類損失 | 越小越好 |
| **val/dfl_loss** | 驗證集分布損失 | 越小越好 |

## 📊 2. 驗證結果圖表解讀

### 2.1 混淆矩陣（Confusion Matrix）

**文件**：`confusion_matrix.png` 和 `confusion_matrix_normalized.png`

**解讀**：
- **對角線**：正確預測的數量（應該最大）
- **非對角線**：錯誤預測
- **Normalized 版本**：顯示百分比，更容易比較

**理想情況**：
- 對角線值接近 1.0（100%）
- 非對角線值接近 0.0

### 2.2 Precision-Recall 曲線

**文件**：`BoxPR_curve.png`

**解讀**：
- **X 軸**：Recall（召回率）
- **Y 軸**：Precision（精確度）
- **曲線下面積（AUC）**：越大越好
- **理想情況**：曲線接近右上角（高 Precision + 高 Recall）

**你的情況**：如果曲線接近右上角，表示模型在精確度和召回率之間取得良好平衡。

### 2.3 Precision 曲線

**文件**：`BoxP_curve.png`

**解讀**：
- **X 軸**：Confidence Threshold（信心度閾值）
- **Y 軸**：Precision（精確度）
- **意義**：在不同信心度閾值下的精確度表現

**使用建議**：
- 如果曲線在低閾值時就很高，表示模型很自信
- 可以根據此曲線選擇最適合的 confidence threshold

### 2.4 Recall 曲線

**文件**：`BoxR_curve.png`

**解讀**：
- **X 軸**：Confidence Threshold（信心度閾值）
- **Y 軸**：Recall（召回率）
- **意義**：在不同信心度閾值下的召回率表現

**使用建議**：
- 如果曲線在低閾值時就很高，表示模型能檢測到大部分目標
- 與 Precision 曲線一起看，找到最佳平衡點

### 2.5 F1 分數曲線

**文件**：`BoxF1_curve.png`

**解讀**：
- **X 軸**：Confidence Threshold（信心度閾值）
- **Y 軸**：F1 Score（Precision 和 Recall 的調和平均）
- **意義**：綜合評估模型性能

**使用建議**：
- **最高點**：對應最佳的 confidence threshold
- F1 分數越高，表示 Precision 和 Recall 的平衡越好

## 📋 4. 關鍵指標總結

### 4.1 Precision（精確度）

**定義**：在所有預測為「人」的結果中，有多少是正確的

**公式**：Precision = TP / (TP + FP)

**你的結果**：97.7% ✅
- **意義**：當模型說「這裡有人」時，97.7% 的情況下是正確的
- **應用**：適合需要高準確度的場景（如人數統計）

### 4.2 Recall（召回率）

**定義**：在所有真實的「人」中，模型檢測到了多少

**公式**：Recall = TP / (TP + FN)

**你的結果**：93.5% ✅
- **意義**：真實存在的人中，93.5% 被成功檢測到
- **應用**：適合需要不漏檢的場景（如安全監控）

### 4.3 mAP50（Mean Average Precision @ IoU=0.5）

**定義**：在 IoU 閾值為 0.5 時的平均精確度

**你的結果**：98.1% ✅
- **意義**：當允許 50% 的重疊時，模型的平均精確度
- **標準**：> 0.95 為優秀

### 4.4 mAP50-95（Mean Average Precision @ IoU=0.5:0.95）

**定義**：在 IoU 閾值從 0.5 到 0.95 的平均精確度（更嚴格）

**你的結果**：77.2% ✅
- **意義**：在更嚴格的標準下，模型的平均精確度
- **標準**：> 0.70 為良好，> 0.80 為優秀

## 🔍 6. 常見問題

### Q1: Precision 和 Recall 哪個更重要？

**A**：取決於應用場景：
- **人數統計**：Precision 更重要（避免多算）
- **安全監控**：Recall 更重要（避免漏檢）
- **你的情況**：兩者都很高，平衡良好 ✅

### Q2: mAP50 和 mAP50-95 的差異？

**A**：
- **mAP50**：較寬鬆的標準，允許 50% 重疊
- **mAP50-95**：更嚴格的標準，要求更高的定位精度
- **你的情況**：mAP50 很高，mAP50-95 良好，表示模型定位準確

### Q3: 如何選擇 Confidence Threshold？

**A**：
1. 查看 `BoxF1_curve.png`，找到最高點
2. 查看 `BoxPR_curve.png`，找到 Precision 和 Recall 的平衡點
3. 根據應用需求：
   - 需要高精確度：提高 threshold（如 0.5）
   - 需要高召回率：降低 threshold（如 0.25）

### Q4: 損失值還在下降，需要繼續訓練嗎？

**A**：
- 如果 **驗證集指標已經很好**（如你的情況），可以停止
- 如果 **驗證集指標還在提升**，可以繼續
- 如果 **出現過擬合**（驗證集指標下降），應該停止
